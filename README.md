# Cyber Trust mark 2025

A self-assessment / preparedness tracker for Singapore's **Cyber Trust mark** certification
(based on the Cyber Trust and Cyber Essentials publications, v202504).

The app is a single-page HTML tool that lets an organisation work through the
certification tiers and track how prepared they are for each requirement.

## Contents

- `index.html` — current preparedness tracker UI.
- `index-ascent.html` — "The Ascent" UI variant.
- `index-credential.html` — "Credential" UI variant.
- `cyber-trust-v202504.pdf`, `cyber-essentials-v202504.pdf` — source reference publications.

## Status

Early prototype. Functional starting point, with UI still being iterated on.
